# Publication history

## Original snapshot — November 6, 2026

The [initial commit](https://github.com/oramada/pbit1-research/commit/d4a0b22614b638afc08ebfe15f3212d271b42cb5)
contains the original private research snapshot, manuscript, and verification
records. Its files remain available in Git history.

[`PUBLICATION_20261106.json`](PUBLICATION_20261106.json) preserves the initial
visibility and SDK snapshot metadata. The large historical `archive/` and the
frozen scientific result files have not been rewritten for this public release.

## Public-access revision — November 8, 2026

The repository is published at the author's request. This revision adds:

- a plain-language overview, evidence map, and graded reproduction guide;
- overview charts derived from the existing accepted result summary;
- a manuscript access-status correction and rebuilt PDFs;
- artifact/link checks suitable for a public checkout.

It introduces no new neural experiments and changes no accepted model scores.
Historical references to a private or unpublished snapshot describe the state at
their recorded dates. The current README and `PUBLICATION.json` describe the
public research repository.

[`PRE_PUBLIC_SCAN.json`](PRE_PUBLIC_SCAN.json) records the credential-pattern and
sensitive-filename checks of the original tracked snapshot and bundled archive
members. This is a bounded automated scan, not a guarantee against every possible
sensitive item.
